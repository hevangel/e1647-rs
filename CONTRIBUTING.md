# Contributing

Open an issue with a minimal reproducer and the language construct it targets. Please state whether the behavior is specified by IEEE 1647, a documented extension, or an assumption.

Contributions must be independently written. Do not submit copied proprietary Specman source code, internals, vendor documentation, or copyrighted IEEE specification text. Add tests for new syntax or semantics, and run `cargo fmt`, `cargo clippy --all-targets -- -D warnings`, and `cargo test`.
